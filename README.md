# Fast Mahjong

A 3D Mahjong Solitaire web app with seeded daily puzzles and random practice boards.

## Tech stack

- TypeScript and React 19
- Three.js via React Three Fiber and Drei
- Zustand
- Tailwind CSS v4 and Radix UI / shadcn/ui
- Vite and Bun

## Development

```bash
bun install
bun dev
```

## Build and quality checks

```bash
bun build
bun format
bunx biome check
```
